# OECT Atlas

面向 OMIECs（有机混合离子电子导体）与 OECT（有机电化学晶体管）的中文知识门户原型。

## 本地预览

直接用浏览器打开 `index.html` 即可。该原型不依赖构建工具或第三方包。

## 后续内容维护

九个版块的初始信息集中在 `script.js` 的 `topics` 数组中。每当补充论文时，可为条目补充：研究问题、材料/结构、关键方法、核心结论、局限性及 DOI；再逐步替换当前的框架说明。

## PDF 文献收藏

在本项目发送论文 PDF 后，按 [文献收藏流程](LITERATURE_WORKFLOW.md) 完成全文阅读、高清整图与图注截图、中文逐图解读和网站归档。当前 CANs 文献使用 `script.js` 中的文章对象与分类列表；图片保存在 `assets/`，裁切来源记录在 `notes/`。
